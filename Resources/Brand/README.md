# Provider identification assets

These assets identify the corresponding providers, not a-watcher's own brand.

- `codex.png`, `codex-dark.png`: OpenAI's installed ChatGPT macOS distribution, `Contents/Resources/icon-codex-light.png` and `icon-codex-dark-color.png`. Official product: https://openai.com/codex/ . OpenAI retains its marks.
- `claude.png`: Anthropic's official Claude Code VS Code extension `anthropic.claude-code-2.1.318-darwin-arm64`, `resources/claude-logo.png`. Official extension: https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code . Anthropic retains its marks.

- `pi.svg`: the official square badge from the [Pi Press Kit](https://pi.dev/press-kit), downloaded from [pi.dev/favicon.svg](https://pi.dev/favicon.svg). `pi.png` and `pi-dark.png` render the original paths in the two colors specified in the SVG for light and dark appearances.

The application renders small thumbnails in memory. No affiliation or endorsement is implied.
