# Codex 首个可运行版本

2026-11-06，用户明确授权“Claude 先不要管，先把 Codex 接通”。此决定解除此前的 Claude 额度权限等待，不再尝试读取 Claude 凭据，也不要求用户完成 Claude 登录。

本次交付：原生菜单栏应用、实际 Codex 账户额度、只读会话与本机 token 统计、持久化增量索引、用量详情、手动与自适应额度刷新。AppKit 管理菜单栏与弹层，SwiftUI 描述面板；额度仅数字，不使用进度条。

数据口径与限制：

- 额度跟随 Codex 当前登录账户，使用已实际验证的原生查询；不常驻 CLI，不写 auth.json。
- 本机用量是本机已记录日志，账户额度包含其他设备，两者不混为同一范围。
- 开始和本轮完成来自日志证据；旧的运行证据显示待确认。精确批准/输入等待的 hook 接入及通知尚未交付，不更改现有 Codex hooks 或信任设置。
- 读取按块限量、逐块 autoreleasepool，游标与派生记录同事务提交。半行不入账；文件替换/截断重建。
- 活跃/归档副本按事件身份去重；子会话领先的父会话回放比对实际父记录排除。缺少父记录时保守排除并提示部分统计。
- 当前保护性跳过超过 2 MiB 的单行，压缩 `.jsonl.zst` 尚未解析；这两类情况必须在详情标为部分统计，不能宣称完整总数。
- 费用估算、通知、开机启动、多目录编辑与精确会话跳转留待后续。用户本轮缩小到 Codex 首接入，本版本不宣称整个一期已经完成。

工程零第三方运行依赖，系统 sqlite3 存派生数据，不复制提示词或工具输出。自包含 Swift 检查器运行合成语料，避免依赖本机缺失的 XCTest / Swift Testing 互操作库；不为运行测试要求安装完整 Xcode。

## 验证

`bash Scripts/check.sh` 运行核心行为检查；`bash Scripts/build.sh` 构建 Release 应用并本地 ad-hoc 签名。受外层沙箱限制的开发宿主可设置 `AW_SPM_NO_SANDBOX=1`，只关闭 SwiftPM 构建沙箱，应用运行设置不变。

## 本轮实际验证

- 核心行为检查：**16 项通过、0 失败**。覆盖累计/增量去重、计数重置、compaction 顺序及修正、半行、超大行尾部、动态额度窗口、账户不匹配、重启/截断、fork 后续追加、compaction 原始日期及归档副本。
- Release CLI 真实扫描：退出码 0；暖缓存约 0.86 秒，144 个明文文件，30 个近期会话。具体数量随 Agent 写入变化。[记录](codex-cli-check.json)
- 正式应用的额度适配器真实 HTTP 查询成功，原生渲染时账户额度有效、当前账户仅有一个 7 日窗口；不是演示数字。
- 完整应用短时检查约 154 秒，峰值 physical footprint **48.74 MiB**、RSS **79.06 MiB**，末次 footprint **33.16 MiB**；没有记录末次面板可见性，不把它冒充严格的关闭弹层基准。[采样](codex-first-runtime.json)
- 后段约 108 秒 CPU 均值 **0.0174% 单核口径**。`proc_pid_rusage` 的 CPU counter 按本机 Mach timebase 125/3 换算；与独立进程 CPU 时钟核对的比值约 1.0002。[计时核对](cpu-counter-check.json)
- Release `.app` 包未压缩约 **1.99 MB**，本地签名通过 `codesign --verify --strict`。
- 原生视图导出已实际查看亮/暗主面板、额度、用量和设置，修复窄列符号换行，部分统计提示前置。导出仅包含应用自身的视图。[渲染状态](native-render-check.json)
- 电脑控制工具尝试检查原生界面时超时；因此 **实际鼠标点击、键盘返回、VoiceOver 和手动交互尚未完成验收**。原生视图的程序化页面切换不能替代这些证据。
- 短时验证不等于 10 分钟完整应用基准、动态 10 会话压力、8 小时稳定性、休眠恢复或 Intel 实机。此前 10 分钟数据来自空壳样机，应分开理解。

本机当前确有未读取的压缩归档、被跳过的大行和缺父记录的子会话，应用明确展示部分统计；当前小计不宣称与 ccusage 全量报告一致。Agent 配置与 auth.json 均未更改，Claude 未接入。
