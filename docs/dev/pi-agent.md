# Pi 接入验证 · 2026-11-16

本次实现提供 Pi 会话索引、本机用量与可选实时扩展。使用方法见 [README](../../README.md#使用-pi)，扩展边界见 [架构说明](../tech/architecture.md)。

| 验证入口 | 观察结果 |
|---|---|
| `AW_SPM_NO_SANDBOX=1 bash Scripts/check.sh --native-file-events` | 48 项核心检查通过，含原生文件监听，以及 Pi 的父文件后到、非前缀继承、独立会话相同条目 ID、重启、摘要和工具用量、字段缺失、过期状态与合并完成通知。更新签名检查通过。原生 FSEvents 用例在外层沙箱之外运行。 |
| `AW_SPM_NO_SANDBOX=1 bash Scripts/build.sh` | 本地 Release 构建与深度签名校验通过。应用包内含扩展源文件。 |
| `python3 Tests/Pi/check-host.py /path/to/pi` | 在临时目录用 Pi 1.5.2 的真实 RPC 入口和进程内测试模型，分别观察到等待批准、工作、成功/错误/取消。仅成功快照携带完成记录。测试会话使用隔离配置。 |
| Release App + Pi 1.5.2 RPC | 两个进程使用相同的临时数据目录。应用的菜单栏活动记录依次出现等待（0 工作）、工作（1 工作）、完成（0 工作、1 未读）。另一次成功会话中，模型给出输入 8、输出 2，`watcherctl scan --provider pi` 从实际 Pi 日志读到 10。 |
| 本机只读索引 | 1 个真实 Pi 会话文件，经有界增量读取产生 115 条账本记录，未报告跳行。未读取 Pi 凭据。 |
| `--export-showcase` | 检查合成数据的原生首页、Pi 详情与年度历史图。首页可容纳三个来源及完整的今日数字。该项只验证渲染。 |

用量支持带稳定条目 ID 的 v2/v3 会话。现代 Pi 的 assistant、工具执行、压缩、分支摘要、独立用量记录均从 usage 读取；缓存包含在输入总数中。老格式缺少条目身份、缺父文件、不可读路径或损坏字段会降低覆盖程度。Pi 没有统一的七日账户额度。

实时扩展兼容范围按 Pi 1.5.2 起的 1.x 接口声明，本次运行验证版本为 1.5.2。在没有可持久化会话文件的模式中扩展不发布状态。每个扩展实例保留最近 32 个成功时间，应对文件事件合并。这里的运行结果来自短时验证。
