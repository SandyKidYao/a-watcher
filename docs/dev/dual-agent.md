# 双 Agent 本地接入与单图标方案

2026-11-06：用户澄清仅 Claude 剩余额度实地查询暂缓，Claude 的本地状态、会话和用量都要接入。随后指定：菜单栏一个图标，完成提醒先做几个 HTML 方案；面板所有 Agent 额度放同一行、仅显示 7 日百分比，footer 为今日总 token；统计默认每小时更新。

## 已实现

- Claude 与 Codex 使用独立的增量索引、缓存与来源身份，共用本地读取与存储基础设施；列表可按 Agent 筛选，用量按 Agent 查看今日/7 日/30 日。
- Claude 输入合计包括普通输入、缓存读、缓存写；同一消息流式修订更新最终值，重写 request ID 的复制历史按 Anthropic 消息身份去重，未完成请求明确降低覆盖度。
- Claude 状态识别用户输入、工具调用、明确的 AskUserQuestion 等待输入、end_turn 结束与 API 错误。max_tokens/refusal 不误报任务完成；精确批准等待依然需要后续事件接入。
- 仅 Codex 查询账户额度。Claude 没有额度客户端，不读取凭据、不登录或查询账户接口。
- 去重后的用量持久化为 canonical 缓存，避免状态变化时反复对全部历史分组。
- 完整统计每小时刷新。状态由文件事件独立读取：已知文件最多 64 KiB 尾部，新文件另读最多 2 MiB 头部；不更新统计账本。手动刷新保留。
- 面板额度一行、各 Agent 仅显示自己的 7 日剩余；footer 合计今日 token。默认统计更新可能落后实时活动，这与状态及时更新是不同口径。
- 官方图标采用本机 OpenAI macOS 发行包及 Anthropic Claude Code 官方扩展的原始资源，见 [来源](../../Resources/Brand/README.md)。菜单栏已采用用户选定的 B 活动波形。

[HTML 候选报告](../../.xiaobai/design/2026-11-06-menu-icon-options.html)提供三个独立图标方向，可模拟开始、工作、部分完成、全部完成、需要介入，以及打开面板清除未读。

用户已选择 B 活动波形。原生实现开始轻亮，工作波形最多三轮，随后静止；部分完成保留工作波形并显示未读点，全部已知工作完成显示勾。打开面板清除当前未读；完成记录去重并按数据根目录保存少量哈希收据，重启后保留。错误或中断不作为成功完成；冷启动建立基线，旧日志不会产生新完成提醒。

## B 动效原生验证

[隔离日志驱动的原生测试](activity-wave-check.json)覆盖实际文件事件到菜单栏状态的链路：开始、两个 Agent 同时工作、部分完成保留工作、重复完成不再计数、全部完成勾选、重启恢复未读、程序化打开面板后清除。验证环境不提供账户凭据，因此没有额度请求。工作动画在实际运行中记录为三次循环；减少动态效果或低电量时关闭动效。

这是原生事件链路和程序化面板验证，不冒充实际鼠标点击或录屏验收。统计仍每小时更新，状态监听与完成提示独立工作。未读收据只保存计数和事件哈希，不保存对话内容。

B 图标的空闲、工作和完成三种原生形态已导出并检查，完成勾与未读点保持分离。动画由 Core Animation 执行有限次数，没有常驻绘制 timer；仅为过期状态证据安排一次性复核。
