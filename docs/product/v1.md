# 产品定位与一期范围

阶段更新（2026-11-06）：用户已明确先接通 Codex、暂缓 Claude。本文保留原始双 Agent 一期目标；当前 0.1.0 仅为 Codex 首接入版本，已实现与后续事项以 [开发记录](../dev/codex-first.md) 为准。

## 定位

一个安静常驻的本机仪表：看一眼就知道哪个 Agent 正在工作、哪里需要我介入、今天用了多少、账户还剩多少额度。

目标用户首先是同时使用 Codex 和 Claude Code 官方订阅的本机开发者。使用终端、IDE 或桌面端的具体覆盖必须按实际数据与 hook 能力验证，不能把“安装了 CLI”当作所有宿主均已兼容。

## 一期完整能力

| 能力 | 必须交付的行为 | 验收要点 |
| --- | --- | --- |
| 工作状态 | 空闲、运行、使用工具、等待批准、等待输入、完成、错误、未知 | 有明确证据才标记等待或完成；不因一段时间没日志就判完成 |
| 会话 | 同时展示两种 Agent、多会话、项目、宿主、最近活动、父子会话 | 同一项目不同会话不合并；父子关系与用量归属不混淆 |
| 返回工作现场 | 打开已验证的会话链接或定位支持的终端；否则打开所属应用 | 未验证精确跳转时明确只支持打开应用；不承诺通用终端逐 tab 定位 |
| 本机用量 | 今日、7 日、30 日、自定义日期；按 Agent、项目、模型、会话聚合 | 增量解析、跨日计数、重启不重复、重复日志不重复 |
| token 明细 | 输入、输出、缓存读取、缓存写入；可用时给出推理细分 | 缓存、推理的包含关系按 Agent 格式归一化；不重复相加 |
| 费用参考 | API 等价估算、价格来源和日期、缺价覆盖情况 | 订阅账户不显示为真实账单；未知模型显示未定价 |
| 账户额度 | 两种官方订阅的可用窗口、已用/剩余百分比、重置时间 | 显示来源、采集时间；窗口由服务端返回，不把所有套餐硬编码为 5h/7d |
| 额度补充 | 服务端提供时显示模型专属窗口、积分或额外用量 | 缺字段表示未知/不适用；无限额不显示为 100% 剩余 |
| 通知 | 等待用户、完成、失败、低额度；分类开关与免打扰 | 默认克制；相同会话状态、同一额度窗口的同一阈值不重复提醒 |
| 设置 | 数据目录、监控接入、刷新、通知、外观、开机启动、清理缓存 | 保留其他工具配置；用户可以撤销本工具接入 |
| 降级体验 | 无会话、首次索引、未接入、凭据不可用、离线、格式变化 | 旧数据保留原采集时间；认证失败或换账户时不把旧账户数据冒充当前值 |

“一期全部功能”解释为上述三大监控维度均可用，而非复制参考项目的所有外围功能。用户已选定菜单栏为一期入口，刘海和悬浮条留作后续候选。主面板采用符号与关键数字，完整信息可在详情访问，简化布局不删减监控能力。

## 核心旅程与验收故事

- **U01 接入**：启动后自动检测默认目录；显示状态、用量、额度各自的就绪情况。允许先只读观察，再开启精确事件。已有 hooks 完整保留。
- **U02 工作**：同时运行两种 Agent，菜单栏显示忙碌数；打开弹层看到每个会话与项目。事件到达后，正常负载下状态呈现延迟目标 p95 ≤ 1 秒。
- **U03 介入**：出现待批或待输入时，会话前置并按设置通知。点击回到支持的宿主；不由监控工具代替批准。
- **U04 统计**：切换日期和 Agent 可查看 token 明细。停止并重启 a-watcher 后同一份日志统计不变，流式更新的最终输出不会丢失。
- **U05 额度**：能够读取两种官方订阅额度；断网后显示“上次采集于…”及过期标记；换账户后隔离缓存。
- **U06 轻量**：弹层关闭后停止 UI 动画与倒计时绘制，不产生周期性全量日志扫描；达到性能文档里经验证的资源门槛。

## 首期边界提案

监控本机，不提供云同步、远程 SSH、手机端、团队后台、Agent 调度、自动批准、账户切换或代登录管理。可设置多个数据根目录，但首期额度跟随每种 Agent 当前官方登录账户；无法从历史日志确认账户时，用量标注“这台 Mac”，不强行归属到当前账户。

通知阈值、默认日期、面板宽度属于可调整默认值。具体分发许可证与 macOS 最低版本在实际开工前确认。
