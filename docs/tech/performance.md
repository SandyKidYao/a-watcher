# 资源预算与技术验证

以下全部是**待确认、待测量的目标**，不是已有测量。最终验收同时看 Activity Monitor 可见表现与测量记录，不以语言选择代替性能证据。

## 暂定预算

| 场景 / 指标 | 第一轮目标 | 说明 |
| --- | --- | --- |
| 空闲、弹层关闭 | physical footprint ≤ 40 MiB，争取 ≤ 25 MiB | 发布版、稳定后；同时记录 RSS，二者不混用 |
| 弹层打开、10 个会话 | 稳态 footprint ≤ 65 MiB | 包括实际 UI 和缓存 |
| 额度刷新 / 首次索引峰值 | 所有自有进程合计 ≤ 120 MiB | helper 峰值必须算；不足时先重新设计，再与用户调整预算 |
| 无 Agent 活动的空闲 CPU | 10 分钟均值 < 0.1% 单核 | 明确 macOS 100% = 一核；记录测量分辨率和采样开销 |
| 10 个活动会话 | 10 分钟均值 < 1% 单核 | 固定合成事件速率，另测真实使用 |
| 空闲唤醒 | 应用自有周期性 UI timer 为 0；总唤醒目标 < 1 次/秒 | 网络、文件系统事件与系统归因另记 |
| 状态延迟 | hook 接收到 UI 呈现 p95 ≤ 1 秒 | 不包含 Agent 自身未发事件的时间 |
| 冷启动 | 图标可交互 ≤ 1 秒 | 历史索引不阻塞启动；开发机首次权限提示另记 |
| 增量 IO | 未变文件不重复解析；新内容按字节增量读 | 另核对事件丢失后的有界恢复扫描 |
| 应用体积 | arm64 发布包压缩后争取 ≤ 15 MiB | 不含系统框架；真正发布前量包 |

## 测量口径

- 固定开发机、macOS、Release 编译选项、供电/低电量、数据集大小、事件速率；保留日期、版本和命令。
- 空壳、接一个来源、接两个来源、额度刷新分别测；同时记录常驻和瞬时峰值。
- 统计 a-watcher、bridge、额度 CLI 及其可归属子进程；不把 Agent 本身正常工作开销算入，却必须计入监控主动启动的探测进程。
- 用 Instruments / xctrace 查看 Time Profiler、Allocations、Energy 与文件活动；系统不允许的测量明确写未测。采样器自身开销与被测应用区分。
- 每个稳定场景至少 10 分钟；长稳态运行 8 小时，观察 FD、任务、数据库和物理占用增长；休眠/唤醒重复 5 次。
- Rust 对照只有在需要时进行：相同原生 UI、同一事件集、同一持久化语义、同样 helper 生命周期；不能拿 Rust CLI 对比完整 Swift GUI。

## 建议先做的三个小验证

| 验证 | 问题 | 通过证据 | 时间盒建议 |
| --- | --- | --- | --- |
| S1 状态链路 | 当前两种 Agent 的实际宿主能否只读发出关键状态？ | 运行、工具、批准/输入等待、结束和中断的对照轨迹；已有 hooks 不变 | 半天 |
| S2 账户额度 | 当前官方订阅凭据能否以可接受权限和峰值查询？ | 两种来源各一次真实快照；离线、401、轮换、取消与超时验证 | 半天至一天 |
| S3 原生资源基线 | 图标、弹层、增量读取能否达到预算？ | Release 空壳和模拟 10 会话的进程合计测量 | 半天 |

这里尚未执行这三项集成实验；本轮已做的是本地字段和协议能力核查。尤其额度接口未实测，不能在文案或原型上声称已接通。

## 首期必须覆盖的正确性样本

半行与非法 JSON、文件替换与截断、缺模型/价格、累计计数重复与重置、Claude 流式最终值、fork 和子 Agent 回放、compaction、归档迁移、跨日、时区切换、未知版本、hooks 乱序、重启恢复、额度账户变更、无权限、429 退避、休眠恢复、子进程超时与回收。

使用合成日志与脱敏结构，不将本机真实聊天作为仓库 fixture。与固定版本 ccusage 对比用量只是交叉证据，遇到差异要追溯事件和口径，不能直接认为任一工具必然正确。

## 首轮实际结果

已完成 [2026-11-06 可行性验证](spikes/2026-11-06-validation.md)，包含两种 UI 样机的 600 秒以上空闲测量、真实账户查询、合成 bridge 延迟和大日志读取。目标表仍是完整应用门槛，不能用空壳通过代替最终应用验收。Claude 额度权限、大行覆盖、真实宿主等待状态和长期稳态仍未通过或未验证。

Codex 0.1.0 后续完成约 154 秒的完整应用短时检查：峰值 footprint 48.74 MiB、末次 33.16 MiB，约 108 秒后段 CPU 均值 0.0174%（单核）。CPU 已核对 Mach timebase；完整口径与限制见 [当前开发记录](../dev/codex-first.md)。此短测不替代目标表中的完整时长与压力场景。
