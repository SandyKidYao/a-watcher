# 交互与 UI 设计：精简菜单栏

## 设计方向

关键词：安静、清晰、精确。视觉以用户选定的活动波形作为识别符号；用克制的单色、系统字体和对齐来体现轻量。色彩只用于正在运行、需要介入、错误等语义，不以持续动画证明程序“活着”。

用户已确认一期采用 **菜单栏图标 + 弹层**，并要求进一步减少文字、多用符号。本次将弹层从约 360 pt 收窄为 **320 pt**，把重复说明收进悬停提示与详情。当前版本保留用户确认的紧凑布局，并已按 Impeccable 原生工具界面方法进行一轮 review 与修订。

不开 Dock 主窗口；关闭弹层后卸载非必要视图、停掉 UI 动画和倒计时 timer。真实 macOS UI 用 AppKit，HTML 仅用于评审，不打包进应用。

## 形态决定

| 形态 | 展示重点 | 优势 | 代价 / 建议 |
| --- | --- | --- | --- |
| 菜单栏弹层 | 图标显示忙碌和待介入；点击查看状态、额度与用量 | 外接屏、无刘海设备都可用；隐藏时几乎无绘制 | 用户已选定，一期实现 |
| 刘海条 | 屏幕顶部显示最近活动 | 多会话状态更醒目 | 后续候选，一期不做 |
| 悬浮胶囊 | 固定短条显示两种 Agent 状态 | 状态常见 | 后续候选，一期不做 |

## 信息层级

1. 菜单栏：单一 B 活动波形。开始轻亮，工作时起伏三轮后静止，完成时勾选并保留未读点；部分完成仍保留工作主体。打开面板清除当前未读。
2. 弹层头部：小型 a-watcher 名称，刷新与设置图标。
3. 额度区：所有 Agent 放在同一行，官方图标旁仅显示各自的 7 日剩余百分比；Claude 额度暂缓显示“—”。其他窗口在详情查看，不使用进度条。
4. 会话区：按待介入、待确认、运行、最近完成排序。每行只显示 Agent 符号、项目名、状态符号与简写时间（如 12s、4m）；活动内容和 Agent 全名放入悬停提示与详情。筛选使用全部 / Codex / Claude 三个图标按钮，旁边用会话图标与数字标出当前可见数量。
5. 页尾：太阳图标 + 今日两种 Agent 合计 token + 单位；存在缺失时保留部分统计标记。完整统计与额度默认每小时更新，状态按事件轻量更新。
6. 二级详情：额度来源和采集时间、token 细分、7/30 日趋势、项目/模型/会话筛选。点击后仍在同一弹层上下文内，以返回图标回到总览。长详情滚动，不撑大或截断主弹层。

## 符号规则

- 正式界面使用 OpenAI 官方 macOS 发行包与 Anthropic 官方 Claude Code 扩展中的图标；来源见 `Resources/Brand/README.md`，不再使用抽象尖括号。
- `●` 工作、`◆` 等待批准、问号圆圈等待输入、`✓` 本轮完成、`○` 状态待确认。待批准与待输入不能共用一个含糊的等待标记。
- 状态同时靠形状与颜色区分；每个图标按钮、账户行、会话行都有完整的可访问名称和悬停说明。项目名保留为文字，不把所有信息强行编码成图标。
- 额度仍明确标“剩余”，保留窗口与单位；离线保留“离线 · 18m”这类短提示，不能为精简而隐藏数据过期或认证问题。
- 用户明确要求额度不使用进度条；主面板和额度详情均只用窗口、剩余百分比与必要的重置时间表示。
- 默认显示静态符号，无持续旋转、闪烁或脉冲。

## 核心操作

- 点击菜单栏符号打开/关闭；Esc 返回上一级，再关闭。点击外部关闭；可选固定面板。
- 点 Agent 行看该账户的额度详情；筛选会话可分别看 Codex / Claude，且总览中两个账户始终可达。
- 点会话看详情并提供“返回会话”操作。未验证精确跳转时操作名改为“打开应用”。
- 状态提示能说明需要哪类介入，但不在这里批准工具调用。
- 打开设置查看三个独立就绪项：状态监控、本机统计、账户额度；不要用一个“已连接”掩盖局部失败。

## 状态规范

| 状态 | 符号和文字 | 行为 |
| --- | --- | --- |
| 运行 | 实心点；悬停提供活动描述 | 静态显示；非必要不脉冲 |
| 等待批准 | 菱形；悬停标“等待批准” | 前置；按开关通知一次 |
| 等待输入 | 问号圆圈；悬停标“等待输入” | 前置；与工具批准区分 |
| 完成 | 对勾；悬停标“本轮完成” | 短期保留，之后收进最近记录 |
| 未知 | 空心圈；悬停标“状态待确认” | 展示最后证据时间；不猜测 |
| 额度过期 | 时钟 + 简短采集年龄，另有离线短提示 | 保留旧值但标过期；提供刷新 |
| 认证不可用 | 钥匙提示 + 需要授权/重新登录 | 不冒充 0% 或旧账户当前值 |
| 首次索引 | 索引进度 + 已覆盖日期 | 已知小计先显示，标统计尚不完整 |
| 无会话 | 无活动会话 | 已有历史和账户额度仍可查看 |

## 视觉 token

`tokens.json` 为平台无关草案。亮色为冷灰背景、白色表面、深灰文字；暗色为深石板背景和浅灰文字。系统字体 11/12/13/15/20 pt，数字用等宽数字特性，不强制整段代码字体。间距 4/8/12/16/24，面板圆角 16、内部控件 6–8，边框和阴影只表示层级。

正文对比度目标 ≥ 4.5:1；状态文字与图形目标 ≥ 3:1；颜色不作为唯一状态线索。亮暗主题均需脚本计算与成品检查。支持键盘焦点、VoiceOver、减少动态效果、降低透明度；正式版适配系统强调色和本机显示缩放。

## 原型范围与检查

评审 HTML 现仅保留已选菜单栏形态，提供亮暗主题，工作/待批/待输入/离线/未知/空会话/未接入七个场景、Agent 筛选、额度和用量详情、设置演示。所有数字和会话均为合成数据，不读取本机，不执行登录或改设置。

原型视觉不能证明原生应用的布局、可访问性或性能；原生实现还需独立验收。

## 本轮设计依据

用户提供的 Stats 截图用于菜单栏信息层级参考；品牌图标来自官方发行包。面板采用中性系统表面、克制边框、清晰的数字字号与官方色彩图标。亮暗预览与实际本机数据在当前原生应用中生成；不将原生渲染导出冒充鼠标点击测试。

## 最新交互约束（覆盖前述旧稿）

- 菜单栏只放一个图标。开始、工作中、完成的动效先比较 A 方形状态灯 / B 活动波形 / C 任务栈；重点是完成的一次提示和持续未读标记。方案文件：`.xiaobai/design/2026-11-06-menu-icon-options.html`。用户已选择 B，原生应用已实现有限次数的活动波形与持久完成未读标记。
- 所有 Agent 的额度在同一行，每个官方图标旁只显示各自 7 日剩余百分比；不将不同账户额度相加。Claude 额度显示“—”，本地功能正常。
- footer 展示 Codex + Claude 的今日本机 token 合计，并保留部分统计提示。
- 完整本机用量扫描和账户额度默认每小时更新；首次接入、手动刷新和休眠恢复可立即更新。状态事件独立读取变更日志的有界头/尾片段，不等待一小时。

## 已选定：B 活动波形

用户选择 B。开始时短暂亮起；工作状态三根波形轻微起伏三轮后静止；部分完成保留工作主体并增加未读点；完成后勾选和未读点保留到打开面板。重启保留未读，错误/中断不计成功完成，旧历史不重新提醒。减少动态效果与低电量使用静态形态。

## 历史用量页

主面板 footer 今日 token 恢复为入口，右上角增加网格图标。历史页按需展开为约 760 × 500 pt，主面板仍为 320 pt。年度热力格以周为列、周一至周日为行，支持按年和 Agent / 合计筛选；使用单个 Canvas 绘制。每日颜色按当前非零记录分档，悬停展示准确数值，点击或日期选择器查看当天明细。未来日期以淡虚线区分，缺记录用语明确为“无已索引本机记录”。

- 会话标题旁信息按钮打开状态图例；正在工作/使用工具为蓝色，完成为绿色，需要输入/批准为琥珀色，错误为红色，待确认为灰色虚线圆。所有状态同时有不同形状、可访问名称与文字说明。

- 未增加常驻任务、周期性扫描或无限动画。原生方法下不使用仅适用于 Web 的 Impeccable detector。
